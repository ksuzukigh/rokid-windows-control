# Rokid Control for Windows 仕様書

## 1. 文書情報

- 対象製品: Rokid Control for Windows
- 初期製品バージョン: 1.0.0
- 対応元: Rokid Control for macOS 1.2.4
- 対象機器: Rokid AI Glasses RV101
- 文書状態: 実装開始版
- 更新日: 2026-08-01

## 2. 目的

Rokid AI Glasses RV101の画面をWindows PCへ表示し、PCのマウスとキーボードから安全に操作できるようにする。画面、カメラ映像、入力、接続情報はPCとRokidの間だけで扱い、クラウドへ送信しない。

## 3. 対応環境

### 3.1 正式対応

- Windows 11 24H2以降
- x64 CPU
- 信頼できるプライベートWi-Fi
- Rokid開発用5ピンケーブル
- Rokid側でADB開発者モードが有効

### 3.2 初期版で正式対応しない環境

- Windows 10 Home / Pro
- Windows on ARM
- 32ビットWindows
- 公共Wi-Fi
- Rokid AI Glasses RV101以外の機器

Windows 10は技術的に動作する可能性があるが、Microsoftの通常サポートが終了しているため試験対象に含めない。Windows on ARMは公式scrcpy Windows x64版を含む全体の実機確認後に判断する。

## 4. 配布

- 表示名: Rokid Control
- アプリアイコン: Mac版の`RokidGlasses.icns`と同じデザインを使用し、Windows版は16～256pxを含むマルチサイズICOとしてEXEとメインウインドウへ適用
- リポジトリ名: `rokid-windows-control`
- 配布形式: 自己完結型x64アプリを収録したポータブルZIP
- 正式配布物: `Rokid-Control-Windows-x64-<version>.zip`
- 配布場所: GitHub Releases
- インストール範囲: 現在のユーザー
- 通常利用時の管理者権限: 不要
- .NETランタイム、ADB、scrcpy、必要DLLは配布物へ同梱

Windowsのセキュリティ設定によっては確認画面が表示されたり、実行が許可されない場合がある。利用者に保護機能の無効化は求めない。

### 4.1 公開条件

次の条件をすべて満たしてから、GitHub Releasesへ一般公開する。

1. Windows版のUI調整を完了する。
2. Windowsの表示倍率100%、125%、150%で、文字切れ、操作不能、重要情報の欠落がないことを確認する。
3. 起動、モード選択、接続中、再接続、エラー、終了の各状態で、文言と操作が分かりやすいことを確認する。
4. Rokid実機で表示と主要操作を再確認する。
5. 技術試験計画の必須項目をすべてPASSにする。
6. ZIPとSHA-256を検証する。
7. リリース候補の画面と内容を利用者が確認し、公開を明示的に承認する。

ローカルまたはGitHub Actionsで候補ZIPを生成することは、一般公開には該当しない。GitHub Releasesへのリリース作成は公開操作として扱い、上記の確認と利用者の承認より前には行わない。

## 5. 起動

1. アプリは同時に1つだけ起動できる。
2. 二重起動時は既存のウインドウを前面へ表示する。
3. 起動ごとに次の表示モードを選択する。
   - ライブ映像
   - 背景なし（省電力）
   - キャンセル
4. ライブ映像を選択した場合、電池消費が増える旨を表示し、開始または戻るを選択する。
5. 初期版では、表示モードの変更には再起動が必要。

## 6. 接続

### 6.1 接続順序

1. ADBサーバーを開始する。
2. USB接続中のRokidを探す。
3. USBが見つかった場合は、暗号化された無線接続を準備し、最大15秒探索する。
4. 動的なTLS接続先を確認できた場合は無線へ切り替え、確認できない場合はUSBを使用する。
5. USBがない場合は、保存済みWi-Fiアドレスへ接続する。
6. `adb devices`にある接続済みネットワークRokidを探す。
7. `adb mdns services`でRokidを探索する。
8. 最大60秒、1秒間隔でUSBとWi-Fiを再探索する。

### 6.2 接続先の検証

`ro.product.model`と`ro.product.manufacturer`を読み、次のいずれかを含む機器だけを受け入れる。

- `rokid`
- `rv101`
- `rg-glasses`

Rokid以外のWi-Fi ADB機器へ接続した場合は直ちに切断し、そのアドレスを保存しない。

### 6.3 保存情報

- Wi-Fiアドレス: `%LOCALAPPDATA%\Rokid Control\wifi-address.txt`
- ライブ映像の見やすさ: `%LOCALAPPDATA%\Rokid Control\live-visibility.txt`
- ログ: `%LOCALAPPDATA%\Rokid Control\Logs\Rokid Control.log`

保存済みアドレスがRokid以外を指した場合は削除する。

### 6.4 USB接続時の安全方針

1. USBで見つけた端末がRokidであることを検証する。
2. Rokid独自のWi-Fi有効設定とAndroidのWi-Fiを有効化する。
3. Android標準の`adb_wifi_enabled`を有効化し、初回USB認証で登録されたPCだけが使えるTLS接続を準備する。
4. `_adb-tls-connect._tcp`で通知された動的な接続先だけを使用し、接続後にもう一度Rokidであることを検証する。
5. TLS接続に成功した場合だけ、そのアドレスを保存して無線へ切り替える。
6. 無線接続を確認できない場合はUSBを使用し、USBシリアルをWi-Fi接続先として保存しない。
7. `adb tcpip 5555`と固定5555番ポートは使用しない。
8. USB切断後は、保存済みWi-Fi、`adb devices`の接続済みネットワークRokid、mDNSの順で既存接続を再利用する。
9. `service.adb.tcp.port`と`persist.adb.tcp.port`を読み、ポート番号にかかわらず暗号化されていないADB入口が一つでも残っている接続先は採用しない。
10. USB接続時は`adb usb`で暗号化されていない入口を閉じ、端末状態を読み直して閉鎖を確認してから無線へ移行する。状態を読み取れない、または閉鎖を確認できない場合は起動を中止する。
11. mDNS通知が見えない場合は、USB経由で確認したIPv4アドレスと`service.adb.tls.port`を予備候補に使用する。採用前のRokid確認と安全確認は省略しない。

この処理は「Wi-Fi ON」が採用しているAndroid標準の暗号化接続と同じ設定を使う。従来の`adb tcpip 5555`のようにadbdを固定ポート方式へ再起動しない。
保存済みまたは`adb devices`に残っている固定5555番接続は切断し、保存情報からも削除する。

WindowsではADB用USBドライバが必要になる場合がある。ドライバがない場合、アプリは「USB機器を確認できません」と表示し、デバイスマネージャーの確認手順を案内する。特定のドライバはRV101で署名と互換性を確認するまで同梱しない。

## 7. Windows操作モード

接続中はRokidへ監視スクリプトを配置する。

- ハートビート: 5秒間隔
- 監視期限: 20秒
- Wi-Fiが無効になった場合は再度有効化
- PCアプリ終了または異常停止後は、期限切れによって監視スクリプトも停止

画面休止防止はscrcpyの`--stay-awake`と`--screen-off-timeout=86400`を使用する。scrcpy終了時に元の設定へ復元する。監視スクリプトから定期的な`KEYCODE_WAKEUP`や`KEYCODE_UNKNOWN`は送らない。

Mac版の残存ファイルと衝突しないよう、Windows版は`rokid_windows_control_*`という別名を使う。

## 8. 背景なし（省電力）

- 公式scrcpyの表示ウインドウを使用する。
- 音声を転送しない。
- scrcpy標準のキーボード転送を無効にする。
- マウス操作はscrcpyの制御機能を使用する。
- タイトル: `Rokid AI Glasses RV101（Windows操作モード）`
- Rokidの解像度を`wm size`から取得し、失敗時は480×640を使用する。

起動引数の基準:

```text
--serial <serial>
--no-audio
--keyboard=disabled
--window-title=Rokid AI Glasses RV101（Windows操作モード）
```

## 9. ライブ映像

### 9.1 入力映像

HUD用とカメラ用の2つのscrcpyプロセスを起動する。

同一端末上で2本のscrcpyサーバーが同時に初期化される競合を避けるため、カメラを先に確立してからHUDを開始する。どちらもサーバー接続前に終了した場合は、対象プロセスだけを作り直す。

HUD:

```text
--serial <serial>
--no-audio
--max-fps=15
--keyboard=disabled
--window-borderless
```

カメラ:

```text
--serial <serial>
--video-source=camera
--camera-ar=4:3
--camera-fps=15
--orientation=270
--no-audio
--no-control
--window-borderless
```

### 9.2 Windows側の取得

- Windows Graphics Captureを使用する。
- プロセスIDから対象ウインドウのHWNDを特定する。
- 利用者に選択UIを表示せず、対象ウインドウを直接指定する。
- カーソルを取り込まない。
- 受信用ウインドウは画面外へ移動し、Alt+Tabへ表示しない。
- 出力はRokidの画面サイズ、15fpsとする。

画面外ウインドウの継続取得がGPUまたはWindows更新によって不安定な場合は、scrcpyのデコード済みフレームを直接受け取るネイティブブリッジへ切り替える。利用者向け仕様は変更しない。

### 9.3 合成

1. カメラとHUDを出力領域へアスペクトフィルする。
2. HUD強度はスライダー値`v`に対して`0.5 + 3.8v`とする。
   - 最小値は旧最小値の半分
   - 最大値は旧レンジのおよそ30%（強度4.3）に相当
3. 見やすさスライダーではHUD輪郭を膨張させず、全域で元の線幅を維持する。
4. カメラを背景、HUDを前景としてスクリーン合成する。
5. 黒いHUD画素はカメラへ影響させない。

### 9.4 表示

- タイトル: `Rokid AI Glasses RV101（ライブ映像）`
- 最小クライアントサイズ: 360×480
- 通常のタイトルバーを表示し、移動・最小化・最大化・サイズ変更・終了を可能にする
- 起動時は、ウィンドウが表示されるディスプレイの作業領域内へ収める
- 利用者がウィンドウを移動、サイズ変更、最大化した後は、ライブ映像への切替で位置・サイズ・最大化状態を変更しない
- Rokid画面と同じ縦横比を維持
- 背景: 黒
- Mac版と同じく、映像の上部へ「文字・アイコンの見やすさ」「薄い」「濃い」とスライダーを表示
- スライダーは`薄い`と`濃い`の間で利用可能な横幅いっぱいに伸ばす
- スライダー範囲: 0.0から1.0
- スライダー全域を、実機で輪郭が太くにじまない実用濃度範囲へ割り当てる
- 初期値: 0.9
- 前回値を保存
- 左クリック: 表示位置をRokid座標へ変換してタップ
- 右クリック: `KEYCODE_BACK`

### 9.5 Rokid純正カメラ

- ライブ映像用カメラの受信が停止した場合、`dumpsys activity activities`の現在の最前面Activityを確認する。
- `com.rokid.os.sprite.assistserver`または`com.android.camera2`の純正カメラが最前面なら、カメラ再取得を繰り返さず、HUD用画面転送に含まれるフルカラー撮影画面へ切り替える。
- Activity履歴に残ったカメラや`Photo to Mac`など別アプリは純正カメラと誤判定しない。
- 純正カメラ終了後は、ライブ用カメラ受信とHUD合成へ自動的に戻す。
- 切替中は状況を画面に表示し、タイトルを`Rokid AI Glasses RV101（純正カメラ）`へ変更する。

## 10. キーボード

Rokidウインドウが前面の場合だけ処理する。他のアプリが前面の場合は監視結果を破棄し、ADBへ送らない。

| Windowsキー | Rokidの動作 |
| --- | --- |
| `H` | どの画面からでもウェイクして下段中央のHomeを直接選ぶ |
| `M` | どの画面からでもメモを直接開く |
| `A` | どの画面からでもアプリ一覧を直接開く |
| `←` / `→` | `A`でアプリ一覧を開いた直後だけ、アプリを選択 |
| `Enter` | アプリ一覧を開いた直後だけ、選択中のアプリを開く |
| `Esc` | 常に一つ戻る |
| `Alt+F4` | Windows標準の終了 |
| `Ctrl+Q` | 互換終了操作 |

キーの自動リピートは転送しない。

下段リングと下段選択モードは設けない。画面移動は`H`、`M`、`A`の1キーで即時実行する。`←` / `→`とEnterは、`A`でアプリ一覧を開いた後だけ有効にする。アプリを開いてEscで一覧へ戻っても選択状態を維持し、時間経過、Enter、Esc、または別アプリからRokid画面へフォーカスを戻すクリックでは終了しない。`H`、`M`、またはライブ映像の直接操作で終了する。`↑` / `↓`は横取りしない。

Windows画面には、Rokidの下段アイコンと同じ順の`M メモ　H Home　A アプリ`を常時表示する。アプリ一覧の選択中は`← → 選択　Enter 決定　Esc 戻る`へ切り替える。これらの案内はRokidへ送信せず、Windows側だけに表示する。

背景なし画面は、起動時と再接続時に自動的にキーボード入力先へ切り替える。他のWindowsアプリが前面にある間はRokidへキーを転送しない。

メモとアプリ一覧を直接開く座標:

- Y: 画面高の1/2
- メモ X: 画面中央から画面幅の1/15左
- アプリ一覧 X: 画面中央から画面幅の1/15右

## 11. 再接続

- 通常再接続: 最大20回、1秒間隔
- 現在の接続がWi-Fiなら一度切断して再接続
- USBが見つかった場合は、起動時と同じ暗号化Wi-Fi準備と動的TLSへの移行を試す
- 動的TLSへ移行できない場合だけUSBを使用
- 直前の接続がUSBであっても、保存済みWi-Fiアドレスを次に使用
- 固定5555番の直前・保存済み・接続済みアドレスは再利用しない
- 最後にmDNS探索
- 復旧後は監視スクリプトを再開し、画面サイズを再取得

背景なし画面のscrcpyが異常終了した場合、またはRokidとの接続が失われた場合は自動再接続する。利用者が背景なし画面の×を押して正常終了した場合は、再接続せずアプリ全体を終了する。

scrcpyが5秒以内に2回以上終了した場合、自動再起動を止めて「再接続」または「終了」を選択させる。

ライブ映像:

- 画面取り込みの再作成: 最大5回
- カメラ再起動: 2秒間隔、最大15回
- HUD再起動: 2秒間隔、最大5回
- カメラ競合中: `撮影中です… カメラ映像の復帰を待っています`
- 純正カメラ中: HUD用画面転送をフルカラー撮影画面として表示し、純正カメラ終了後にライブ背景へ復帰
- HUD初期化競合中: `HUD画面を再接続しています…`
- HUD接続停止時: 接続全体を再構築
- USBで一時復旧した後にUSBが外れた場合: 保存済みWi-Fiアドレスへ自動的に戻る

## 12. 終了

背景なし画面の×、`Alt+F4`、`Ctrl+Q`はいずれもアプリ全体の終了操作として扱う。

1. キーボード監視を停止する。
2. ライブ映像取得を停止する。
3. scrcpyプロセスを終了する。
4. Rokid側監視スクリプトを停止する。
5. 一時ファイルを削除する。
6. ログを閉じる。

終了処理が400msを超えた場合は「終了しています…」を表示する。次回起動時には、このアプリが起動した残存scrcpyプロセスだけを整理する。

### 12.1 配布とコード署名

- GitHub Releasesから自己完結型ZIPとSHA-256を配布する。
- 初回公開版はコード署名を付けない。
- コード署名は将来必要になった場合にあらためて検討する。
- Microsoft StoreとMSIXでの配布は対象外とする。
- 自己署名証明書は一般配布に使用しない。
- 開発や試験のためにSmart App Control、Microsoft Defender、PowerShell実行ポリシーを無効化しない。
- 詳細は`docs/CODE-SIGNING.md`に定める。

## 13. エラーとログ

- 利用者向け文言は日本語
- エラー画面に「閉じる」と「ログを表示」を用意
- ログの最大サイズ: 2,000,000バイト
- 1世代だけローテーション
- ADBコマンドの引数、終了コード、タイムアウト、接続状態を記録
- キーの種類は記録してよいが、通常の文字入力内容は記録しない

## 14. プライバシーと安全

- クラウド通信を行わない。
- 更新確認を初期版へ含めない。
- 接続対象はRokidと確認できた機器に限定する。
- 公共Wi-Fiでの使用を案内しない。
- Windowsファイアウォールで許可が必要な場合はプライベートネットワークだけを対象にする。
- 管理者権限でアプリ本体を起動しない。

## 15. 受け入れ条件

- USB接続とWi-Fi接続の両方でRokid画面を表示できる。
- 初回USB認証後に暗号化Wi-Fiへ切り替わり、以後はUSBケーブルなしで接続できる。
- 無線接続にはmDNSで通知された動的TLSポートを使用し、固定5555番ポートは使用しない。
- 背景なしモードで全キーボード操作とマウス操作が動作する。
- ライブ映像が15fpsで継続表示され、Mac版と同等のHUD合成になる。
- カメラを使うRokidアプリ終了後、ライブ映像が自動復帰する。
- 他のWindowsアプリへ入力中のキーをRokidへ送信しない。
- 一時切断後に自動再接続する。
- 通常終了後、PCとRokidの両方に動作中プロセスを残さない。
- 通信を遮断した環境でも、クラウド接続を要求せず利用できる。
