# Rokid Control for Windows 実機テスト報告

## 総合結果

**合格**

2026年8月1日に行った立会い再試験では、修正後のR00からR12をすべて合格と記録した。途中で確認されたアプリ一覧の選択操作と、無線接続中のキー入力重複は修正後に再試験し、合格を確認している。

この判定は、下記の「確認した機能」の範囲に限る。未確認の項目は、本報告の合格判定に含めない。

## 確認した機能と結果

| 分類 | 確認内容 | 結果 |
| --- | --- | --- |
| 接続 | USB接続でRokid 1台を認識し、平文ADB入口がない状態で起動できた。 | 合格 |
| 接続 | ライブ映像中にUSBを外し、暗号化Wi-Fiだけで30秒以上、表示と操作が継続した。 | 合格 |
| 接続 | 無線接続中にUSBを再接続しても、表示・操作が中断せず、二重表示・二重操作が発生しなかった。 | 合格 |
| 接続 | USBを再度外した後も、暗号化Wi-Fiだけで30秒以上安定した。 | 合格 |
| 接続 | USBを外したままアプリを終了・再起動し、保存済みの無線接続でライブ映像が復帰した。 | 合格 |
| 画面表示 | ライブ映像で、カメラ映像とRokidの文字・アイコンが正しく合成された。 | 合格 |
| 画面操作 | `A`、`←` / `→`、`Enter`でアプリ一覧の選択・起動ができた。 | 合格（修正・再試験後） |
| 画面操作 | `Esc`で一覧へ戻った後、10秒経過とフォーカス復帰後も選択操作が継続し、`H`で選択状態が終わった。 | 合格 |
| 画面操作 | 無線接続だけの状態で`M`、`H`、`A`、`Esc`を各1回の操作として実行できた。 | 合格（修正・再試験後） |
| 撮影機能 | Rokid純正「カメラ」をRokid側で開き、Windows表示がフルカラーの撮影画面へ切り替わった。 | 合格 |
| 撮影機能 | 純正「カメラ」を閉じると、Windows表示がライブカメラとHUDの合成へ戻り、10秒以上安定した。 | 合格 |
| 背景なし（省電力） | 2026年7月29日にWindowsアプリから実画面を表示した記録がある。最終立会い再試験での表示・カメラ切替・無線再接続の一連の確認は**未確認**。 | 一部確認 |
| 終了処理 | 正常終了後、PC側のRokid Controlとscrcpy、Rokid側の生存信号・監視PIDが残っていないことを確認した。平文ADB入口も残っていなかった。 | 合格 |
